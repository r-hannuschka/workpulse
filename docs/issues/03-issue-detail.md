# Issue: Issue Detail

**Prio:** P2 — Nice-to-have, Browser-Wechsel vermeiden

## Problem

Der Benutzer muss in den Browser wechseln, um Details eines Tickets nachzuschauen.

## Ziel

Issue-Details direkt im Webview anzeigen — Beschreibung, Kommentare, Labels, Attachments.

## Akzeptanzkriterien

- [ ] Beschreibung (gerendert) aus Jira laden
- [ ] Kommentare auflisten
- [ ] Labels, Priority, Status anzeigen
- [ ] Link zum Ticket in Jira
- [ ] Wird aus Buchungsliste oder Timer per Klick auf Issue geöffnet

## Hinweis

Erspart den Browser-Wechsel wenn man nachschauen will, was man da überhaupt macht.
