# Issue: Dashboard Monthly Chart – Tag-Klick zur Tagesansicht

**Prio:** P3 — Kleinere Verbesserung des bestehenden Charts

## Problem

Auf dem Dashboard gibt es einen Monthly-Chart. Der Benutzer will von dort nicht manuell in die Buchungsliste navigieren und Tag auswählen, sondern direkt zur Tagesansicht springen.

## Ziel

Im bestehenden Monthly-Chart auf dem Dashboard:
- **Klick auf einen Tag** im Chart springt direkt zur **Tagesansicht** in der Buchungsliste
- Navigation ist nahtlos (kein manuelles Suchen)

## Akzeptanzkriterien

- [ ] Klick auf einen Tag im Monthly-Chart löst Navigation aus
- [ ] Öffnet die Buchungsliste (Woche) mit dem entsprechenden Tag ausgewählt
- [ ] Navigierter Tag ist visuell hervorgehoben
- [ ] Kein manueller Schritt zwischen Chart und Buchungsliste

## Hinweis

Das ist eine **Erweiterung** des bestehenden Monthly-Charts auf dem Dashboard, keine neue Seite.
