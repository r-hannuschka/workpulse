# Issue: Timer / Stoppuhr

**Prio:** P0 — Muss sein, Kern-Funktion

## Ziel

Ein **Widget auf dem Dashboard**, mit dem man:
- Ein Issue auswählen kann
- Timer starten, pausieren und stoppen kann
- Live sieht, wie viel Zeit verstrichen ist

## Akzeptanzkriterien

- [ ] Timer-Widget auf Dashboard (neben dem Monthly-Chart)
- [ ] Issue-Auswahl über Dropdown (Liste aller offenen Issues)
- [ ] Timer: Start, Pause, Stop
- [ ] Live-Zeit-Anzeige im Widget
- [ ] Zeit-Eintrag wird automatisch bei Stop gebucht
- [ ] Zustand bleibt beim Panel-Neuladen erhalten (Timer läuft weiter)

## Hinweis

Das ist die **Hauptaktion** des Tools. Timer-Widget + Dashboard = der Einstiegspunkt.
