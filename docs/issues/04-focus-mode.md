# Issue: Focus Mode

**Prio:** P2 — Nice-to-have, reduzierter View für konzentriertes Arbeiten

## Problem

Das Dashboard ist zu voll und lenkt ab, wenn man nur an einem Issue arbeiten will.

## Ziel

Ein reduzierter View mit:
- Einem Issue im Fokus
- Timer (Start, Pause, Stop)
- Keine Issues-Liste, kein Dashboard-Drumherum

## Akzeptanzkriterien

- [ ] Vom Dashboard in Focus Mode umschaltbar
- [ ] Zeigt nur ausgewähltes Issue + Timer
- [ ] Zurück zum Dashboard-Button
- [ ] Timer-Logik identisch mit Timer/Stopuhr-Issue

## Hinweis

Der **Kontrast-Modus** — für die Zeit wo man konzentriert arbeitet und nichts anderes sehen will.
