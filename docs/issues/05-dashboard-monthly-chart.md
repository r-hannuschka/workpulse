# Issue: Dashboard Monthly Chart

**Prio:** P1 — Existiert bereits als Widget, soll erweitert werden

## Problem

Der Benutzer hat keine visuelle Übersicht, wie viele Stunden er pro Monat gearbeitet hat. Er müsste in die Buchungsliste wechseln, um das herauszufinden.

## Ziel

Auf dem Dashboard einen **Monthly-Chart** anzeigen:
- Balkendiagramm mit Stunden pro Monat (letzte 6–12 Monate)
- Klick auf einen Balken springt direkt zur Buchungsliste (Woche) für diesen Monat

## Akzeptanzkriterien

- [ ] Balkendiagramm (Monate x Achse, Stunden y Achse)
- [ ] Zeigt letztere 6–12 Monate
- [ ] Balkenhöhe = Gesamstunden im Monat
- [ ] Klick auf Balken → springt zur Buchungsliste (Woche) für den Klick-Monat
- [ ] Dashboard bleibt der Einstiegspunkt, Chart ist ein Widget darauf

## Hinweis

Das ist ein **Widget auf dem Dashboard**, keine eigene Seite. Der Chart ist die schnelle Übersicht, die Buchungsliste die detaillierte Ansicht.
